# Decisions

Non-blocking choices, one line each with the reason. Decisions that change scope or the spec are also called out in the milestone status message.

## M0

| #   | Decision                                                                                                                                                                                 | Reason                                                                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Build in the existing empty repo jsab258/Sentrax (branch claude/sentrax-3d-rtls-demo-jtoerz) instead of creating a new repo named sentrax-3d-demo. The package is named sentrax-3d-demo. | This session is scoped to that repo; it can be renamed or transferred on GitHub without code changes. Scope deviation, flagged in the M0 status. |
| 2   | npm as package manager, Node 22.                                                                                                                                                         | Preinstalled, simplest CI setup, lockfile committed.                                                                                             |
| 3   | TypeScript 6.0, not 7.0.                                                                                                                                                                 | typescript-eslint supports TypeScript below 6.1 only.                                                                                            |
| 4   | React 19, three 0.186, React Three Fiber 9, drei 10, @react-three/postprocessing 3, zustand 5, Vite 8, Vitest 5.                                                                         | Current stable versions that satisfy each other's peer ranges.                                                                                   |
| 5   | Playwright pinned to 1.56.1.                                                                                                                                                             | Matches the Chromium build preinstalled in the dev container; CI installs its own browser.                                                       |
| 6   | Vite `base: './'`.                                                                                                                                                                       | The static build then works from any path: iframe embed, a /demo page or a subfolder.                                                            |
| 7   | The 3D stage (three.js and R3F) is lazy-loaded; `npm run build` fails if initial JS exceeds 400 KB gzip (scripts/check-bundle.mjs).                                                      | Enforces the SPEC budget on every build. M0 initial JS is 69.5 KB gzip.                                                                          |
| 8   | CI runs lint, typecheck, test and build, plus a separate Playwright smoke job.                                                                                                           | The SPEC asks for the first four; the smoke job catches render regressions early and adds no deployment.                                         |
| 9   | Headless Playwright uses software WebGL (SwiftShader flags).                                                                                                                             | Containers and CI runners have no GPU.                                                                                                           |
| 10  | e2e runs against the Vite dev server for now.                                                                                                                                            | Dev tools are needed for M0 to M5 screenshots; M6 switches smoke tests to the production preview.                                                |
| 11  | Milestone screenshots come from e2e/screenshots.spec.ts, gated by `SCREENSHOTS=1`.                                                                                                       | CI never rewrites committed images.                                                                                                              |
| 12  | Dev-only tools (claims overlay, brand sheet) are on in the dev server and in production only with `VITE_ENABLE_DEV_TOOLS=true`.                                                          | Satisfies "dev-only" while still allowing a review build.                                                                                        |
| 13  | The SPEC's allowed figures (RSSI 3 to 5 m, AoA sub-meter, BiLink room-level) and the quoted BiLink tagline are marked approved; every other site-derived statement starts unapproved.    | The SPEC explicitly allows those figures; everything else needs review.                                                                          |
| 14  | Device descriptions come from web search snippets and are all unapproved.                                                                                                                | sentrax.com is blocked from the build environment.                                                                                               |
| 15  | Brand tokens are neutral placeholders with `status: 'placeholder'` and a visible warning in dev.                                                                                         | Brand extraction is blocked; placeholders must never look like Sentrax values.                                                                   |
| 16  | postMessage uses target origin `*` by default, overridable with `VITE_EMBED_PARENT_ORIGIN`.                                                                                              | Messages carry only event names and sizes, and the WordPress origin is not fixed yet.                                                            |
| 17  | Messages to the parent carry `source: 'sentrax-3d-demo'`.                                                                                                                                | Lets the host page filter out unrelated messages.                                                                                                |
| 18  | Fonts will be self-hosted, never loaded from Google Fonts at runtime.                                                                                                                    | No third-party requests or cookies inside the embed.                                                                                             |
| 19  | AgX tone mapping (not ACES).                                                                                                                                                             | The SPEC allows either; AgX rolls off bright interior highlights more naturally.                                                                 |
| 20  | HDRIs come from Poly Haven via the pmndrs/drei-assets GitHub mirror (CC0) and will be self-hosted.                                                                                       | polyhaven.com is blocked while the mirror is reachable; files are the same CC0 assets.                                                           |
| 21  | Models are procedural by default, CC0 or CC-BY models only where clearly better.                                                                                                         | Smaller payload, exact dimensions, no license risk.                                                                                              |
| 22  | People are procedural mannequins behind one Character component, animated procedurally.                                                                                                  | Faceless look as specified, no animation license questions, swappable later.                                                                     |
| 23  | The simulation engine (M1) will be plain TypeScript with no three.js or React dependency.                                                                                                | Runs in Vitest and in the 2D debug view, and keeps PositionSource swappable for a live SOLIX feed.                                               |

## M1

| #   | Decision                                                                                                                                     | Reason                                                                                      |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 24  | UI colors follow the Woodmart theme values the site renders (`#D31F4C`, `#352E86`); the Elementor kit colors are kept verbatim for overlays. | The kit colors are defined but barely visible; buttons, logo and hero use the theme colors. |
| 25  | Secondary UI text uses `#333333` instead of the site's `#777777`.                                                                            | `#777777` on white is 4.48:1, under WCAG AA; `#333333` is also a theme value.               |
| 26  | Brand fonts Lato and Poppins are self-hosted from @fontsource (latin subset, 4 weights).                                                     | SIL OFL 1.1; no runtime requests to Google.                                                 |
| 27  | Device descriptions use the sentrax.com main menu product descriptors verbatim, marked `verifiedAt` but still `approved: false`.             | They are Sentrax's own one-liners; approval stays a human decision.                         |
| 28  | The reference fetcher uses a standard browser user agent, one request at a time with pauses and retries.                                     | The site's bot protection intermittently rejects unusual user agents.                       |
| 29  | The proxy CA was added to the container's browser trust store (NSS) so Playwright can load sentrax.com.                                      | The preconfigured NSS store was empty; TLS verification stays on.                           |
