# Decisions

Non-blocking choices, one line each with the reason. Decisions that change scope or the spec are also called out in the milestone status message.

| 20  | HDRIs come from Poly Haven via the pmndrs/drei-assets GitHub mirror (CC0) and will be self-hosted.                                                                                       | polyhaven.com is blocked while the mirror is reachable; files are the same CC0 assets.                                                           |
| 21  | Models are procedural by default, CC0 or CC-BY models only where clearly better.                                                                                                         | Smaller payload, exact dimensions, no license risk.                                                                                              |
| 22  | People are procedural mannequins behind one Character component, animated procedurally.                                                                                                  | Faceless look as specified, no animation license questions, swappable later.                                                                     |
| 23  | The simulation engine (M1) will be plain TypeScript with no three.js or React dependency.                                                                                                | Runs in Vitest and in the 2D debug view, and keeps PositionSource swappable for a live SOLIX feed.                                               |

## M1

| #   | Decision                                                                                                                                                                                                                                 | Reason                                                                                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 24  | UI colors follow the Woodmart theme values the site renders (`#D31F4C`, `#352E86`); the Elementor kit colors are kept verbatim for overlays.                                                                                             | The kit colors are defined but barely visible; buttons, logo and hero use the theme colors.                                |
| 25  | Secondary UI text uses `#333333` instead of the site's `#777777`.                                                                                                                                                                        | `#777777` on white is 4.48:1, under WCAG AA; `#333333` is also a theme value.                                              |
| 26  | Brand fonts Lato and Poppins are self-hosted from @fontsource (latin subset, 4 weights).                                                                                                                                                 | SIL OFL 1.1; no runtime requests to Google.                                                                                |
| 27  | Device descriptions use the sentrax.com main menu product descriptors verbatim, marked `verifiedAt` but still `approved: false`.                                                                                                         | They are Sentrax's own one-liners; approval stays a human decision.                                                        |
| 28  | The reference fetcher uses a standard browser user agent, one request at a time with pauses and retries.                                                                                                                                 | The site's bot protection intermittently rejects unusual user agents.                                                      |
| 29  | The proxy CA was added to the container's browser trust store (NSS) so Playwright can load sentrax.com.                                                                                                                                  | The preconfigured NSS store was empty; TLS verification stays on.                                                          |
| 30  | The engine runs in plan metres (x east, y north, z up); display names live in src/content/scenes.ts keyed by entity id.                                                                                                                  | Keeps world data free of copy, ready for translation.                                                                      |
| 31  | RF model: log-distance path loss, per-wall and per-door losses by material, per-packet noise and spatially correlated shadowing per link.                                                                                                | Shadowing is what keeps RSSI error from averaging away, as in real buildings.                                              |
| 32  | RSSI parameters tuned to a 3.7 to 4.3 m median error in a 15 m gateway grid (tests) and 4.2 m in the warehouse.                                                                                                                          | SPEC asks for a typical 3 to 5 m error.                                                                                    |
| 33  | AoA: isotropic angular noise of 3 degrees, 2 percent multipath outliers, 70 degree field of view, weighted least squares with one outlier rejection.                                                                                     | SPEC asks for 2 to 5 degrees and a sub-meter median; the tests measure 0.24 to 0.32 m.                                     |
| 34  | BiLink anchors validate presence (filtered RSSI above enter for 2 s), keep it until below exit, relay with 0.2 to 0.6 s latency and send keep-alives every 15 s; SOLIX switches rooms only with a 4 dB margin and never faster than 3 s. | Implements "filter and validate at the anchor" with no flicker and no hallway bleed.                                       |
| 35  | Room anchors are placed over the bed or work area, away from the door.                                                                                                                                                                   | With the door in line of sight, noise briefly assigned passers-by in the corridor (seen in the tests).                     |
| 36  | Per-anchor commissioning thresholds for large rooms, dock doors and the cold room entrance.                                                                                                                                              | One threshold cannot fit a 25 m2 patient room and a 4 m dock zone.                                                         |
| 37  | Tags advertise faster while moving (motion-triggered advertising).                                                                                                                                                                       | All four tag models have an accelerometer; at 1 s intervals a forklift passing a dock anchor gave it only two packets.     |
| 38  | Hybrid fusion: AoA where at least two locators measure, otherwise the BiLink room, otherwise RSSI; an RSSI fix inside a room whose anchor does not report the tag is moved to the nearest room without an anchor.                        | SPEC hybrid rule, plus BiLink negative evidence to keep corridor tags out of rooms.                                        |
| 39  | Rules act only on reported positions, never on ground truth; alerts are suppressed in the first 20 s while tags are located.                                                                                                             | Honest behaviour and no false PAR alarm at start.                                                                          |
| 40  | Gate check-out also fires when a tag passes the dock zone and then goes silent there ("exit by disappearance"), exactly once.                                                                                                            | A pallet inside a closed metal trailer is heard by nothing; this is how dock gates work in practice.                       |
| 41  | Each trailer carries its own PINIX TOW-1.                                                                                                                                                                                                | SPEC W2 needs the trailer to stay visible in the yard; tags inside a metal trailer are not heard. Scope addition, flagged. |
| 42  | Hospital ward modelled at 40 x 20 m (plus lobby) instead of 40 x 25 m.                                                                                                                                                                   | Patient rooms at 5.7 x 7 m and a 3 m corridor fill 20 m; deeper rooms looked oversized.                                    |
| 43  | A NODIX CEN-1 is added in the elevator lobby.                                                                                                                                                                                            | The lobby is the geofence edge; without an anchor there, RSSI from two corridor gateways cannot tell lobby from corridor.  |
| 44  | Hospital: 5 ZENIX LON-2 over the ICU. Warehouse: 24 LON-2 over the racking (a row above each aisle, 7.5 m apart) and 6 over production, and 24 LEN-2 on a 14 m grid at 6 m.                                                              | The spec gives no counts; these are the densities the positioning bands need.                                              |
| 45  | Nurse 3 wears both a TOK-1 badge and the TOB-1 SOS wearable.                                                                                                                                                                             | SPEC lists badges for all staff and one SOS wearable.                                                                      |
| 46  | The 2D debug view is dev-only (`?dev=sim`), with deep links for scene, seed, time, scenario and selected tag.                                                                                                                            | Used for the M1 checkpoint screenshots and later story debugging.                                                          |

Approved at the M1 review (2026-09-26): 41 (trailer tags), 42 (40 x 20 m ward), 43 (lobby anchor), 44 (device counts), 37 (motion-triggered advertising), 40 (exit by disappearance), 39 (startup grace period), 45 (double-tagged nurse), 25 (`#333333` body text).
